# 带货直播间页面

## Context
用户需要一个成人用品带货直播间页面，包含模拟直播画面、商品展示、实时弹幕/聊天、抢购功能等电商直播核心要素。

## 方案

### 页面结构
创建一个**独立全屏页面** `/live`，沉浸式体验，不使用 Dashboard 侧边栏布局。

### 功能模块

1. **直播视频区域**（左侧主体）
   - 模拟直播画面（渐变背景 + 主播信息覆盖层）
   - 在线人数、点赞数显示
   - 主播头像 + 昵称 + 关注按钮
   - 直播标签（如"限时福利"、"新品首发"）

2. **实时弹幕/聊天区**（视频区底部覆盖）
   - 模拟用户评论弹幕滚动
   - 发送消息输入框
   - 自动生成模拟弹幕

3. **商品展示面板**（右侧）
   - 当前正在讲解的商品（大卡片，带倒计时抢购）
   - 商品列表（带价格、原价、折扣标签）
   - "立即抢购" 按钮 + 库存进度条
   - 商品分类标签

4. **底部操作栏**
   - 购物车图标 + 商品数量角标
   - 分享按钮
   - 点赞动画按钮

### 数据来源
使用前端 Mock 数据展示效果，包含：
- 商品列表（名称、价格、原价、图片占位、库存、销量）
- 模拟弹幕消息
- 主播信息

### 设计风格
- 延续暗色主题，适配当前项目设计系统
- 直播间用深色背景配合 primary 色（金色）作为抢购/高亮色
- 商品卡片使用 card 色 + border
- 弹幕使用半透明背景

### 验证
